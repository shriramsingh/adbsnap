3x Faster Parallel Store Bundler

Single-pass phone chassis assembly cached in RAM. Renders Google Play & App Store (6.9", 6.7", 6.5") asset packs concurrently via Promise.all, cutting export time from >8.1s to ~2.5s.

📱 1-Click App Store & Google Play Asset Generation
CI/CD • Release Automation • ZIP Pack

The Problem

Apple and Google demand strict, conflicting resolution standards (6.9", 6.7", 6.5", 7"/10" tablets, plus 1024×500 feature graphics). Manually resizing and framing dozens of screenshots takes hours in design apps.

The ADBSnap Solution

One headless command or Studio click generates an entire store-compliant asset pack with 4K vector bezels, rendered concurrently and packaged into an organized ZIP bundle.

npx adbsnap export --store apple --zip --format webp

Under the Hood

Architecture & Core Components

Engineered for sub-second execution, zero disk latency, and publication-grade 4K vector fidelity.

ENGINE // IO

Direct Framebuffer & Transport

Streams uncompressed RGBA pixel buffers directly from adb exec-out screencap into host RAM in ~52ms with zero on-device disk writes. Auto-detects Android USB/Wi-Fi and macOS iOS simulators (xcrun simctl) and iPhones (devicectl).

COMPOSITOR // SVG

4K Vector Bezel Framing

Mathematical SVG chassis modeling for 2026 flagships (iPhone 16 Pro Max 6.9", Pixel 9 Pro Fold 8", Galaxy S25 Ultra, iPad Pro 13"). Features multi-radius drop shadows, Dynamic Island cutouts, and photorealistic glass edge reflections.

STUDIO // SPA

Studio 2.0 Canvas Engine

Ultra-lightweight native Node HTTP engine booting in <15ms. Supports direct on-canvas drag repositioning with 120 FPS ghost snapping, granular zoom stepper ([ − ] % [ + ] [ 🔍 Fit ]), and multi-aspect artboards.

EXPORT // PARALLEL

Parallel Store Bundler & Cache

Pre-assembles framed phone chassis once in RAM and caches the buffer. Concurrently renders all App Store and Google Play resolutions via Promise.all, slashing export durations from >8.1s to ~2.5s (over 3x speedup).

MOTION // GIF

Animated Story Maker

Compiles multi-screen flows from the filmstrip into high-framerate, smoothly looping animated GIFs with custom step delays (500ms – 4000ms) for animated PR walkthroughs and marketing docs.

IDE // BRIDGE

VS Code Native Bridge

Deep editor integration with Ctrl+Alt+S quick capture, cursor markdown insertion, Demo Mode status bar toggling, and an offscreen <canvas> PNG normalizer for flawless pasting into Slack and Figma.

Quick Start & CLI Reference

Install globally, add to your React Native / Flutter project, or run on demand via npx.

Option 1: Interactive Desktop Studio

Best for visual drag-and-drop framing, headline tweaking, and instant ZIP export:

npx adbsnap studio

Option 2: Headless Command Line

Best for CI/CD pipelines, automated release scripts, and fast local terminal captures:

npx adbsnap snap --title="Track Progress" --theme=sunset
Command Description Key Flags
adbsnap snap Capture screen, apply 4K vector bezel, and export framed showcase image. --aspect=portrait|landscape|square, --format=webp|avif, --theme, --frame
adbsnap demo Toggle Android SystemUI Demo Mode: clean status bar with 9:41 AM, 100% battery, no notifications. on, off, --device
adbsnap studio Launch interactive visual studio with on-canvas drag & 60fps fast-preview. --port=3000
adbsnap export Parallel multi-store asset pack export (App Store & Play Store ZIP). --format=webp|avif|png, --zip
adbsnap doctor Diagnose ADB path, permissions, USB authorization, and dependencies. —
adbsnap devices List attached USB, Wi-Fi, emulator, and iOS simulator/device targets. —
adbsnap explore Autonomous Android bottom-tab crawler: captures each app tab hands-free. --max-tabs=5
adbsnap explore-ios Autonomous iOS UI explorer (XCTest): traverses tab roots & views into App Store screenshots. --bundle, --device, --team, --zip
