Direct RAM Streaming & Raw Framebuffer Screencap

Bypasses slow on-device PNG encoding and filesystem I/O. Streams uncompressed RGBA framebuffers directly from adb exec-out screencap into host RAM, converting to pristine graphics via Sharp in ~52ms with zero disk artifacts.

adbsnap snap --format=webp --frame=galaxy-s25-ultra
📱

2026 Flagship Bezels

Pixel-crisp iPhone 16 Pro Max (6.9" Dynamic Island), Pixel 9 Pro Fold (8" inner foldable OLED), Galaxy S25 Ultra, Android Tablets, and floating frameless styles with realistic shadows.

📦

3x Faster Parallel Store Bundler

Single-pass phone chassis assembly cached in RAM. Renders Google Play & App Store (6.9", 6.7", 6.5") asset packs concurrently via Promise.all, cutting export time from >8.1s to ~2.5s.

🎨

Next-Gen AVIF & WebP Formats

Export ultra-compact assets: AVIF files are 95% smaller (7.3 KB) with superior chroma fidelity; WebP files are 42% smaller (~86 KB) for lightning-fast loading.

📶

Wireless ADB & iOS Simulator

Untether from cables with Android 11+ 6-digit wireless pairing. Plus cross-platform iOS Simulator discovery via macOS xcrun simctl with an instant iOS 🍎 badge.

🪟

Quick Start & CLI Reference

Install globally, add to your React Native / Flutter project, or run on demand via npx.

Option 1: Interactive Desktop Studio

Best for visual drag-and-drop framing, headline tweaking, and instant ZIP export:

npx adbsnap studio

Option 2: Headless Command Line

Best for CI/CD pipelines, automated release scripts, and fast local terminal captures:

npx adbsnap snap --title="Track Progress" --theme=sunset
Command Description Key Flags
adbsnap snap Capture screen, apply 4K vector bezel, and export framed showcase image. --title, --frame, --format=webp|avif, --theme, --device
adbsnap studio Launch interactive visual studio with 60fps fast-preview. --port=3000
adbsnap export Parallel multi-store asset pack export (App Store & Play Store ZIP). --format=webp|avif|png, --zip
adbsnap doctor Diagnose ADB path, permissions, USB authorization, and dependencies. —
adbsnap devices List attached USB, Wi-Fi, emulator, and iOS simulator devices. —
adbsnap explore Autonomous bottom-tab crawler: captures each app tab hands-free. --max-tabs=5
